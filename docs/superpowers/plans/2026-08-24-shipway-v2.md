# Shipway v2 Implementation Plan — OpenShip-replica redesign + missing features

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the dashboard UI to the OpenShip design language (DESIGN.md v2 is binding) and ship the missing product areas: Home, enforced team roles + invites, notification channels/matrix, audit log, global deployments, light/dark mode, Git-URL project source.

**Architecture:** Backend stays the v1 Fastify monolith; additions are one drizzle migration, a role-authorization helper, an audit recorder, a notification event bus + service poller, invite/team/notifications/audit/overview routes. Frontend keeps React/Vite/Tailwind + wouter + TanStack Query but replaces the design system (tokens, primitives, Layout) and restyles/creates every page per DESIGN.md v2 with lucide-react.

**Tech stack additions:** lucide-react, @fontsource/outfit. Everything else unchanged.

**Spec:** `docs/superpowers/specs/2026-08-24-shipway-v2-design.md` (+ v1 spec for unchanged behavior). **Design authority:** `DESIGN.md` (v2) + `PRODUCT.md`.

## Global Constraints

- TypeScript strict; root `npm run typecheck`, `npm run build`, and full server vitest suite green at every commit.
- DESIGN.md v2 is binding for every visual choice: tokens only, Outfit UI face, IBM Plex Mono for data, lucide-react 1.75 stroke, light AND dark verified for every page (class `dark` strategy).
- Bans: side-stripes, gradient text, glass, modals where inline works, em dashes in copy.
- Role enforcement: member<admin<owner; 403 body `{error: 'requires admin'}` / `'requires owner'`. All v1 routes keep their paths/shapes.
- Every mutating route records an audit event (helper injected; failures to record never break the request).
- Terminal log surface keeps fixed dark tokens in both themes.
- Conventional commits with the standard trailer; TDD for all server logic.

### Task 2: Server — migration + roles + audit recorder
**Files:** server/src/db/schema.ts (+users.role/status/inviteToken/inviteExpiresAt; notification_channels; notification_subscriptions; audit_events; projects.repoUrl), drizzle migration 0001, server/src/lib/authz.ts (`roleAtLeast`, `requireRole(app, request, reply, 'admin'|'owner')` returning boolean after replying 403), server/src/services/audit.ts (recordAudit — never throws; purgeAudit(retentionDays); auditConfig get/set via settings keys audit_enabled/audit_retention_days), boot: earliest user → owner when none.
